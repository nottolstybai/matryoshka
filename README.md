# Матрёшка

Ежедневная словесная головоломка: интересный факт, в котором часть слов спрятана во вложенные ребусы. Разгадываешь изнутри наружу — слой за слоем, пока факт не соберётся целиком.

**Играть:** https://nottolstybai.github.io/matryoshka/

```
Мыши боятся {домашний зверь, который мурлычет}ов.
             └─ кот → «Мыши боятся котов.»
```

Ребусы бывают вложенными: внешний можно разгадать только после того, как разгаданы все ребусы внутри его подсказки.

Ответ — одно слово в начальной форме; окончания уже стоят в тексте рядом со скобкой.

## Как устроено

- Чистый HTML, CSS и JavaScript на ES-модулях — без сборки, фреймворков и зависимостей.
- Сервера нет: игра — статика на GitHub Pages, головоломки лежат в `web/data/puzzles.json`.
- Ответы в пуле не хранятся открыто: для проверки — SHA-256 хеш, слово для показа зашифровано AES-GCM ключом из самого ответа. Это защита от случайного подглядывания, а не от перебора.
- Прогресс, серия и архив — в `localStorage` браузера.

```
web/            сайт (то, что выкладывается)
  js/           движок: parser, model, render, crypto, календарь, прогресс
  data/         зашифрованный пул головоломок
tools/          шифрование пула и проверка черновиков головоломок
tests/          тесты (node --test)
puzzles/        открытые головоломки с ответами — только локально, в git не попадают
.claude/skills/ скилл генерации новых головоломок
```

## Разработка

Нужны Node.js 22+ и Python 3 (для локального сервера).

```
make dev      локальный сервер на http://localhost:8000
make test     тесты
make check    проверка синтаксиса
make          список всех команд
```

## Новые головоломки

Головоломки генерирует скилл Claude Code: `/generate-puzzle [число дней]`. Он придумывает факт и ~15 ребусов, проверяет их скриптом (`tools/puzzle.mjs`), отдаёт на экспертизу другой модели, шифрует, коммитит и пушит. Ответы в чат не выводятся — автор тоже играет.

После пуша в `main` GitHub Actions прогоняют тесты и выкладывают сайт.
